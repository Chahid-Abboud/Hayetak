# AI Scripts

AI-related operational scripts are grouped by job type:

- `audit/` - deep audits, chatbot CSV audits, planner batch audits, and GPU/load helpers.
- `training/` - progress predictor training, inference, conversion, and evaluation.
- `data/` - progress predictor data pipelines, cleanup, retraining, and monitoring.
- `selfhosted/` - local coach setup and startup helpers.

Run these scripts from the repository root unless a script says otherwise.
